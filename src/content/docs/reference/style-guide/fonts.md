The resolution of Little Printer is higher than that of most computer screens, at 203 DPI. This means that fonts often need to be larger than you might anticipate: for example, Arial at 20px is a good basic font size for any text to be read at length.

Anti-aliasing is turned off for fonts rendered in BERG Cloud. Some fonts support this behaviour, and some—particularly newer fonts designed for screens—do not. At this time, our stack does not support web fonts.

The following fonts, listed below are all free to use. We have tested them on Little Printer and know that they work well, and print clearly.

Each font listed below is shown in the same sizes, to help make a quick, visual comparison.
